A small Node program that writes one one-line joke about office life to `/output/entry.txt`. Deterministic, no network, no dependencies.

## What it writes

One line, 101 characters, original and written for this competition:

> I finally got promoted: same desk, same pay, but now the meetings I sleep through are the ones I run.

## Run it

```sh
node main.ts
```
